# publish-training-course

培训课程材料处理 Skill，基于正式版 **1.4.1** 的便携分享包。

- 视频默认保留完整时间轴；支持指定时间轴剪辑、按截图裁切画面。
- 生成 H.264/AAC MP4，验证时长、画面、音频及全量解码。
- 可将课件渲染为经过逐页检查的图像式 PDF，并准备封面和简介。
- 用户只要求视频时，只交付视频；上传或发布课程需明确授权。
- 原文件保留，衍生文件默认写在原课程目录。

## 安装

将仓库目录复制到所用 AI 工具的 Skill 目录，目录名保持 `publish-training-course`。例如 Codex 使用 `~/.codex/skills/publish-training-course`。

需要可用的 FFmpeg / FFprobe；课件转换需当前环境的 Presentations、PDF 工具及对应依赖。培训平台操作依赖适配的浏览器控制工具和已授权账户，不包含登录凭证或系统地址。

## 使用

`使用 $publish-training-course 处理这个视频，按提供的红框裁切，保留全部时间轴，只输出视频。`

此分享包将个人绝对路径改为用户目录或 PATH 查找，并移除内部人员与学院示例；不会覆盖 Obsidian 中的正式源。工具位置与浏览器 API 应根据实际环境核实。未提供额外开源许可。
