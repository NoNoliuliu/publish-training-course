# publish-training-course

把原始培训录屏和课件处理成经过验证、可交付的课程材料，并在用户明确要求时协助上传或发布到培训系统。

本仓库是基于正式版 **1.5.0** 整理的便携分享包。它是一套供 AI 助手执行的 Skill 指令与参考流程，需要宿主环境提供文件处理、媒体工具及相应浏览器能力；不是独立运行的剪辑软件或通用培训平台客户端。

## 功能概览

| 功能 | 处理内容 | 关键规则 |
| --- | --- | --- |
| 素材盘点 | 识别原始录屏、课件、已有成品和封面候选 | 保留原文件与历史输出 |
| 视频处理 | 完整视频转封装或转码、指定时间段提取、按授权判断剪辑边界、画面裁切 | 默认不切时间轴、不裁画面；明确要求后才编辑 |
| 课件转换 | 读取完整课件，逐页渲染并生成 PDF | 不使用 WPS；逐页检查后再交付 |
| 封面准备 | 使用已批准封面、合适的课件首页，或按需生成图片 | 检查标题、边距、对比度与缩略图可读性 |
| 标题与简介 | 从完整资料中提炼课程名和一段可直接粘贴的课程简介 | 不编造讲师或课程事实 |
| 成品验证 | 检查媒体参数、画面、音频、完整解码，以及 PDF 页数和版式 | 只报告实际完成的验证 |
| 上传与发布 | 填写课程表单、上传本地材料、核对课程发布状态 | 仅在明确授权及平台条件满足时执行 |

用户可以指定完整材料准备，也可以只要求其中一项，例如只处理视频、只裁画面，或不生成封面和简介。实际交付以用户要求为准。

## 两阶段工作方式

### 阶段一：准备与交付材料

这是默认流程。提供原始视频和课件后，助手准备视频、PDF、封面和简介；用户缩小范围时，只处理指定部分。此阶段不要求培训系统登录、学院分类选择或企业讲师身份，也不会因尚未决定发布而阻塞材料交付。

1. **读取源目录**：盘点录屏、课件、现有成品和封面，确定输出位置。衍生文件默认放在原课程目录；原目录不能写入时先说明情况，再确定其他位置。
2. **确定处理范围**：确认需要哪些成品。视频编辑只补问尚未明确的剪辑方式、时间范围或裁切需求；用户已给出的选择不重复询问。
3. **读取完整课件**：根据主要教学主题确定课程名。去除无关日期、版本后缀和“培训回放”等标签；课程名不附加讲师姓名。一次培训含多个课程时，按各课件主题分别命名。
4. **处理视频**：检查源视频参数与代表性画面，按要求保留、剪辑或裁切，生成兼容的 MP4。
5. **转换课件**：逐页渲染、检查，再组装并复核 PDF。
6. **准备封面与简介**：优先复用已批准封面或合适的课件首页；简介依据完整资料编写，文件中只保留可直接使用的简介正文。
7. **验证与交付**：交付成品链接，简要说明视频时长、验证结果，以及确实存在的限制。

缺失信息只阻塞依赖它的步骤。比如视频范围尚未明确时，仍可继续独立的课件转换和简介准备。

### 阶段二：按需上传或发布

只有用户明确要求上传或发布课程时才进入此阶段。后续要求发布时，优先复用已经交付的材料，除非内容有修订或验证发现问题。

1. **核对材料与授权**：确认封面、视频、PDF和简介可用；填写正式表单前，课程标题和简介须已获用户认可。补齐用户选定的学院、分类及经过核实的讲师身份。
2. **接续已有页面**：优先使用已经登录的浏览器会话和已有“新增课程”表单，保留已填写内容。发现同名课程时，先确定是编辑现有课程还是新建。
3. **填写基本信息**：填写已批准标题、学院、分类、封面和简介；只设置有资料依据的课程标签。
4. **上传本地材料**：为视频和课件建立对应材料行，选择准确讲师与学院素材目录，通过“上传文件”上传已验证的本地文件。等待上传完成并保存，核对成功提示和课程行中的文件名。
5. **复核表单**：检查课程信息、封面预览及每一行材料的名称、讲师、学习时长、下载设置和文件关联。
6. **执行已授权发布**：获得同一课程、版本和发布范围的有效授权后，执行“提交并发布”。发布后搜索课程列表，核实记录显示“已发布”，不能只凭瞬时成功提示判断完成。

**只上传材料不等于授权发布课程。** 已明确授予同一对象、版本和范围的授权持续有效；范围发生实质变化时重新确认。

## 视频处理规则与验证

### 支持的处理方式

- **保留完整时间轴**：默认保留所有内容，包括准备、等待、静音和结束后的片段，不自动删去看起来没有教学的部分。
- **按指定时间轴剪辑**：按用户给出的起止时间提取课程或片段；缺少具体范围时先补齐。
- **由助手判断边界**：仅在用户选择此模式后进行，只删除明确无效的内容；不能确定是否含教学内容时保留或询问。
- **画面裁切**：根据当前视频代表性帧和用户提供的范围确定裁切矩形，去掉多余边框；不会套用其他视频的坐标。单一裁切无法保留全程教学内容时，说明冲突，不强行裁切。

### 编码与检查

优先使用 FFmpeg / FFprobe。目标文件为 H.264/AAC MP4；裁切等视频滤镜需要重新编码。普通精确剪辑默认采用 `libx264`、`veryfast`、`CRF 21`、`yuv420p` 和 `+faststart`。保留源视频帧节奏与音频布局，不随意强制帧率、声道数或采样率。

源文件已经兼容且无需编辑时，避免无必要的重新编码。流复制是经过验证后的可选快速路径，需要确认边界、音画对齐、时间戳及目标播放器兼容性。

交付前检查：

- 时长、分辨率、帧节奏与视频／音频编码。
- 首、中、尾代表性画面；剪辑任务核对指定边界。
- 音频是否存在、起始位置及音画对齐情况。
- 完整文件解码是否成功，不能用仅读取元数据替代全量解码。

具体命令与注意事项见 [视频处理参考](references/video-editing.md)。

## 课件 PDF、封面和简介

### 课件 PDF

通过当前环境的 Presentations 渲染工具将原始幻灯片转为图片，检查每页是否有中文字形缺失、裁切、错位或不可读内容，再按数字页序组装 PDF。保持源页面比例，不拉伸、不裁掉内容。最终核对页数、页面尺寸，并将 PDF 再次渲染以复查显示效果。

此流程生成的是**图像式 PDF**，文字通常不能选择、复制或搜索。需要可搜索文本时，应另行解决该需求，不能直接承诺此流程具备文本层。渲染有缺陷时保留源文件并报告问题，不把有缺陷的图片包装成合格 PDF，也不以 WPS 作为备用转换路径。

详细流程见 [PDF 转换参考](references/pdf-conversion.md)。

### 封面

优先采用已批准的封面，或视觉合适的 16:9 课件首页导出图；否则使用可用的图像生成工具。交付前检查文字、安全边距、对比度和缩略图可读性。

### 标题与简介

课程名依据完整课程资料确定；讲师信息必须有来源支持。简介采用简洁的一段文字，描述课程实际教学内容，不夹带文件路径、剪辑参数、上传说明或未经证实的信息。

## 交付文件与命名

完整材料包通常包含以下四项，使用全角方括号：

| 成品 | 文件名 |
| --- | --- |
| 视频 | `【视频】<课程名称>.mp4` |
| 课件 | `【资料】<课程名称>.pdf` |
| 封面 | `<课程名称>-封面.png`，或合适的 `.jpg` |
| 简介 | `<课程名称>-课程简介.txt` |

原始录屏、课件、封面候选及旧成品均保留。再次生成时使用不同文件名，避免覆盖。默认不另外生成处理报告或发布说明文档；技术检查结果在交付时简要说明。

## 培训平台字段默认值

这些规则适用于 Skill 当前描述的培训平台流程，用户明确指定的值优先：

| 字段 | 默认处理 |
| --- | --- |
| 所属部门 | 保留当前已授权值 |
| 所属学院、课程分类 | 使用用户选定值，不猜测 |
| 素材目录 | 使用对应学院目录 |
| 讲师 | 从企业目录核实准确身份，同名未消歧时需确认 |
| 材料名称 | `【视频】<课程名称>`、`【资料】<课程名称>` |
| 学习时长 | 每份材料默认 **1 分钟**；与视频真实播放时长分别处理 |
| 是否可以下载 | 默认“否” |
| 公开范围、是否必学、推荐、专题、练习、考试 | 用户未指定时保留页面现有默认值 |

课程发布流程是针对已有培训系统表单编写的操作规范。其他平台需核对页面、字段及浏览器 API，并完成适配；不能保证直接适用于所有 LMS。

## 异常与恢复

- 源视频无法读取时报告缺失项，继续可独立完成的材料准备。
- 登录失效时等待用户在对应会话登录后恢复。
- 浏览器连接重置时重新读取页面和表单，核对已有文件关联，保留已完成内容。
- 上传停滞时先判断仍在进行、已完成还是明确失败；只有确认失败后才重试。结果不明时先确认，不重复上传另一份。
- 上传或发布结果须有实际页面证据；不因错误提示反复提交。
- 所需工具缺失时说明具体依赖；未经授权不安装工具，也不绕过访问控制。

## 安装与依赖

将本仓库中的 Skill 文件放入宿主 AI 工具支持的 Skill 目录，目录名保持 `publish-training-course`。例如 Codex 使用：

```text
~/.codex/skills/publish-training-course/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── video-editing.md
    ├── pdf-conversion.md
    └── publishing.md
```

| 任务 | 所需能力 |
| --- | --- |
| 素材读取与输出 | 宿主 AI 的文件读取、写入与命令执行能力，以及对应目录权限 |
| 视频处理 | FFmpeg、FFprobe，相关编码器可用 |
| 课件转换 | 当前环境的 Presentations、PDF 工具及其渲染依赖，Python、Pillow、ReportLab，PDF 检查／渲染工具 |
| 封面生成 | 可用的课件图片导出或图像生成能力 |
| 培训系统上传与发布 | 适配的浏览器控制工具、已登录且有权限的账户、用户提供的学院分类及已核实的讲师身份 |

仓库不包含 FFmpeg、课件渲染器、浏览器插件、登录凭证或培训系统地址。流程来自 macOS 工作环境；本仓库未声明已在所有操作系统或宿主 AI 上完成验证。工具安装位置和 API 应根据实际环境核实。

## 使用示例

**完整准备课程材料**

> 使用 $publish-training-course 处理这个课程目录，准备视频、PDF课件、封面和简介。视频保留完整时间轴，暂不上传或发布。

**精确时间段剪辑**

> 使用 $publish-training-course 提取视频 00:05:20 到 00:48:10，不裁画面，只输出视频。

**仅裁切画面**

> 使用 $publish-training-course 按附图红框裁切视频，保留完整时间轴和音频，不生成封面和简介。

**由助手判断剪辑边界**

> 使用 $publish-training-course 判断课程开始和结束位置，只删除明确无效的片段，保留不确定的教学内容，并准备课程材料。

**上传材料**

> 使用 $publish-training-course 将已验证的课程材料上传到指定学院和分类，先供我核对，不提交发布。

**发布课程**

> 使用 $publish-training-course 发布已确认标题、简介和材料的课程，使用我指定的学院、分类及讲师。
